# OnlineBookStore-Analysis-Using-SQL
Project: Online Bookstore Sales Analysis

In this project, I analyzed data from an online bookstore to uncover key sales metrics. 
I identified which books had the highest sales, the most popular genres, and overall sales trends. 
This analysis helped provide actionable insights for understanding customer preferences and sales performance. 
Through this project, I significantly improved my SQL skills, particularly in writing complex queries, aggregations, and performing data-driven storytelling.

# The goal is to identify key sales metrics

📈 Top-selling books

📚 Most popular genres

💰 Revenue trends over time

🛒 Customer purchasing behavior

## 🛠 Tools & Technologies Used
SQL (MySQL /MS SQL Server Studio)
